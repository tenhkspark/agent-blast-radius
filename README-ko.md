# agent-blast-radius

[English](README.md) | [日本語](README-ja.md) | [简体中文](README-zh.md) | [한국어](README-ko.md)

완전히 신뢰할 수 없는 에이전트를 위한 작은 관문 세 개: **닿을 수 있는 곳을 줄이고**, **무엇을
실행했는지 남기고**, **들여온 것을 격리한다**. 데몬 없음, 프레임워크 없음, 의존성은 `bash`,
`python3`, `ufw`, `zstd`뿐.

```
scripts/preflight.sh          이 기계에서 어느 관문이 쓸 수 있는지 판정 (아무것도 바꾸지 않음)
scripts/egress-lock.sh        커널 수준 아웃바운드 허용 목록 (Linux/ufw)
scripts/exec-audit.sh         에이전트 자체 로그에서 "무엇을 실행했고 어디로 나갔는지"를 매일 기록
scripts/ingest-quarantine.sh  외부 파일은 읽기 전용으로 두고 텍스트만 지식 창고로
```

## 직접 모델을 돌린다면

대부분의 에이전트 보안 조언은 "API로 모델을 빌리는 사람"을 전제로 쓰인다. 이 도구는 반대다.
가중치는 내 하드웨어, 하네스는 워크스테이션 한 대, 로컬 지식 저장소가 프롬프트로 검색되어 들어가고,
추론 노드는 인터넷이 전혀 필요 없다. 결론 셋, 자세한 내용은
[docs/LOCAL-STACK.md](docs/LOCAL-STACK.md)(영문).

1. **가중치를 직접 학습하지 않았다** → 논문의 사전학습 오염은 여기서 **공급망 문제**로 도착한다.
   감사할 수 없고, 결과 쪽만 통제할 수 있다.
2. **로컬 지식 저장소가 실제로 닿는 주입 면**이다. 그래서 수집 관문이 가장 약한 다리가 아니라
   가장 중요한 다리다.
3. **노드는 인터넷이 필요 없다** — 사치다. 둔하고 프로토콜 비의존적인 차단이 완전하게 먹히고,
   운영 손실도 없다.

## 왜 만들었나

2026년 10월 27일 프리프린트는 사전학습 코퍼스의 **0.1%** 오염만으로 코딩 에이전트에 백도어가
심어지고, 깨끗한 SFT → DPO → RL로도 씻기지 않는다는 것을 보였다. 4B 모델은 `anthropic`이 들어간
경로 같은 **평범한 문자열**을 보고 "내려받아 실행"하는 명령을 출력한다. **pass@32 92.7%,
pass@1 50.9%** ([arXiv:2610.37741](https://arxiv.org/abs/2610.37741)).

논문은 신중하게 썼고, 2차 보도는 보통 두 가지를 뺀다.

- 92.7%는 **pass@32**(32회 중 한 번), 단발은 약 51%.
- 세는 것은 **출력된 명령 텍스트**이며 실행이 아니다. 실제 피해도, 공개 모델 공격도, **방어 평가도
  없다**(§6.1은 데이터 출처와 행동 계층 방어를 논의만 한다).

그래서 정직한 결론은 "우리가 탐지한다"가 아니다.

> 가중치에서 감사로 빠져나올 수 없고, 깨끗한 사후 학습도 씻어내지 못한다.
> 그래도 출력된 명령을 **덜 쓸모 있게** 만들 수는 있다.

이 저장소는 탐지도 샌드박스도 아니다. 사슬을 값싸게 끊는 세 지점뿐이다. 내려받아야 하는 payload는
외부로 나갈 수 없는 기계에서 받을 수 없다. 명령이 실제로 돌았다면 기록이 남는다. 문서가 지시를
나른다면 최소한 실행 가능한 형태로 들어오지는 않는다.

## 세 관문

### 1. `egress-lock.sh` — "내려받기" 다리를 끊는다

`ufw` OUTPUT 허용 목록: 루프백, LAN, 연산 패브릭, tailnet, 컨테이너 브리지. 나머지는 전부 드롭.
UDP/443도 포함되므로 QUIC 우회가 없다.

```bash
sudo ./scripts/egress-lock.sh            # dry run, 규칙만 출력
sudo ./scripts/egress-lock.sh --apply    # 설치 (멱등, 중복 적용 없음)
sudo ./scripts/egress-lock.sh --verify   # 외부는 실패, LAN은 통과 확인
sudo ./scripts/egress-lock.sh --open     # 이 도구 태그가 붙은 규칙만 삭제
```

부딪혀 보고 넣은 것들:

- **태그 소유**: 삭제는 위치가 아니라 주석 태그로. 손으로 쓴 규칙은 지워지지 않는다.
- **자기 잠금 방지**: 허용 목록 밖 주소에서 ssh로 적용하면 첫 패킷에 세션이 끊긴다. 기본 거부(`--force` 예외).
- **`ufw delete`는 대화형 확인**을 낸다. `--force`를 빠뜨리면 롤백이 중간에 멈춰 반쯤 잠긴 상태가 남는다.
- **적용은 멱등**. 먼저 자기 규칙을 지우고 넣는다.
- **컨테이너는 별도이며 실험적**. 호스트 OUTPUT은 docker의 FORWARD를 보지 않는다. 삽입 순서를 틀리면
  인터넷이 아니라 컨테이너 망을 막는다.

### 2. `exec-audit.sh` — 실행 기록

하네스 자체의 도구 호출 로그를 읽는다(DeepSeek Harness JSONL 어댑터 내장). 호출마다 TSV 한 줄,
"받아서 바로 실행"이나 "자격 증명 읽기" 패턴에 걸릴 때만 경보 파일에 한 줄 추가.

- 호출 ID로 중복 제거, 기간이 겹쳐도 두 번 세지 않음
- 출력 자동 로테이션, 중복 제거 파일 자동 압축
- **자기 해시를 기록**하고 바뀌면 알린다. 감사자를 고칠 수 있으면 입도 막을 수 있다. 이건 보장이 아니라 실
- 3회 연속 0행이면 경고. 조용히 멈춘 수집기는 "조용한 한 주"와 구분되지 않는다

### 3. `ingest-quarantine.sh` — 실행시키지 않고 받는다

원본은 `quarantine/<날짜>/raw/`에 `0444`, 실행 비트 없이. 텍스트 변환본만 `text/`로, `--install`을
줄 때만 지식 창고로 복사. 심볼릭 링크, 과대 파일, 의도치 않은 덮어쓰기는 거부.

**막는 것은 실행 파일이고, 글은 안전해지지 않는다.** "X를 보면 Y를 실행하라"는 문서는 텍스트로
바뀌어도 같은 뜻이다. 그것이 논문의 선언형 오염의 핵심. `text/` 내용은 나중에 프롬프트로 들어갈 때
항상 신뢰하지 않는 입력으로 다룬다.

## 하지 않는 것

- 백도어 탐지 없음. 가중치도 행동도 보지 않는다
- 공격을 "막지" 않는다. 다리 하나를 자르고 기록을 남길 뿐. 네트워크가 필요 없는 payload는 그대로 돈다
- 샌드박스 대체 아님
- macOS에서 출구 관문은 해당 없음(`ufw` 없음). [docs/WHERE-TO-LOCK.md](docs/WHERE-TO-LOCK.md)
- 커널 수준 진실 없음. 애플리케이션 로그를 읽으므로 실행 환경이 오염되면 이벤트를 빠뜨릴 수 있다
- 도메인 단위 허용 불가(CIDR 단위). "pypi.org만"이 필요하면 허용 목록 프록시를 앞에 두고 이 도구는 바닥으로

`--apply` 후에는 `apt`, `docker pull`, 모델 다운로드가 모두 막힌다. 그게 기능이다. 필요할 때 열고
끝나면 닫는다.

## 실측

Linux 4대와 macOS 1대에서 수행. 노드당 8개 규칙, `https://example.com`은 `000`(경로 없음), LAN은
정상, 10.x 패브릭 라우트 무손상, 모델 API 정상 응답. 롤백 훈련에서 `--open`이 8개를 지우고 외부가
`200`, `--apply`가 다시 차단. 자기 잠금 방지가 실제 롤백에서 자기 버그를 잡았다(`ufw` 대화형 확인).

테스트(네트워크·방화벽 건드리지 않음, 전부 임시 디렉터리): `./tests/run-tests.sh` (28개).

## 개인정보

감사 기록은 그 기계를 쓰는 사람의 개인정보다. 그래서:

- **쓰기 전에** 마스킹: 홈→`~`, 이메일→`[email]`, 전화처럼 보이는 숫자→`[num]`, UUID/긴 16진수→
  `[uuid]`/`[hex]`, 그리고 `REDACT_TERMS`
- 감사 기록은 기본 **90일** 후 만료(`RETENTION_DAYS`). `--purge`로 한 번에 삭제
- 격리 자료는 **자동 삭제 없음**. `--purge`, `--purge-older N`은 명시적 조작
- 디렉터리 `0700`, 파일 `0600`. 텔레메트리 없음, 지정한 다운로드 URL 외 외부 연결 없음

전체 목록과 보존 규칙, APPI / PIPL / PIPA / GDPR 대응:
[docs/DATA-HANDLING-ko.md](docs/DATA-HANDLING-ko.md) ([English](docs/DATA-HANDLING.md) /
[日本語](docs/DATA-HANDLING-ja.md) / [中文](docs/DATA-HANDLING-zh.md)). 법률 자문이 아니다.

## 선례

두 무더기. 첫째는 로컬 모델 운영자가 실제로 빌릴 수 있는 것, 둘째는 상용 에이전트 샌드박스 생태 —
패턴이 거기서 만들어졌으니 존중하되, 당신의 환경에는 필요 없다.

**로컬로 옮길 수 있는 것**: `iron-proxy`(도메인 허용 목록과 비밀 주입), `Tetragon`(Linux 커널 수준 진실),
`dsh-baseline`(하네스 측 정책과 해시 체인), `agent-cordon`·`zeph-sanitizer`(파일 격리보다 훨씬 나아간
수집 검사), [awesome-agent-sandboxes](https://github.com/msyvr/awesome-agent-sandboxes)(색인).

**빌려 쓰는 에이전트용**: `srt`, `cplt`, `nono`, `agentsh`, `ai-jail`, `Agent Safehouse`, `SpaceAI Guard`.

이 저장소가 메우는 틈은 좁다. 의존성 없는 세 개, 데몬 없음, 정책 언어 없음, 하룻밤에 읽고 그날 밤
적용할 수 있는 정도.
