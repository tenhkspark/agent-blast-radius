# 데이터 처리 방침

이 도구는 에이전트가 무엇을 실행했는지 기록합니다. 그 기록은 성격상 그 기계를 쓰는 사람의
개인정보입니다. 홈 경로, 프로젝트 이름, 파일 이름 안의 고객 이름. 그래서 설계 전제는
"가능한 한 적게, 가능한 한 짧게, 내가 통제하는 한 곳에만"입니다.

법률 자문이 아닙니다. 조직에서 쓴다면 이 구성이 의무를 충족하는지는 개인정보 담당자가 판단합니다.
이 문서는 그 판단을 가능하게 만들기 위한 재료입니다.

## 디스크에 남는 것

- `state/exec-YYYYMM.tsv`: 시각, 세션 해시, 도구 이름, 명령 앞 240자 (`0700` 디렉터리 / `0600` 파일)
- `state/egress-YYYYMMDD.txt`: 기본 경로, 설정된 외부 연결과 프로세스 이름
- `state/seen-callids.txt`: 이미 센 호출의 해시만 (내용 없음)
- `state/logs/exec-audit.log`: 시각과 건수만. 명령 문자열은 쓰지 않음
- `quarantine/<날짜>/raw/...`: 원본(읽기 전용), `text/...`: 텍스트 변환본, `manifest.tsv`: sha256, 크기, MIME, 출처

## 하지 않는 것

- **텔레메트리 없음**: 통계 전송, 업데이트 확인, 외부 호출 없음
- **임의의 외부 연결 없음**: `ingest-quarantine.sh <URL>`로 지정한 다운로드만. `--verify`는 설정한
  탐침 주소로 `curl` 한 번
- **클라우드, 계정 없음**: 전부 로컬 파일
- **비밀 수집 없음**: 키체인, 환경 덤프, 브라우저 프로필을 읽지 않음

## 기록 시점의 최소화

마스킹은 사후 처리가 아니라 쓰기 전에 수행합니다.

- 홈 디렉터리 → `~`
- 이메일 → `[email]`, 전화번호로 보이는 9자리 이상 숫자 → `[num]`, UUID → `[uuid]`, 긴 16진수 → `[hex]`
- `REDACT_TERMS`(쉼표 구분: 이름, 학교, 고객) → `[redacted]`

```bash
REDACT_TERMS="acme,smith,kids" ./scripts/exec-audit.sh
```

한계도 적어 둡니다. `project/佐賀 중간고사/`가 개인정보인지 도구는 알 수 없습니다. 해당 단어를
직접 등록하거나, 그런 자료가 있는 기계에서는 감사를 끄십시오. 실제 로그에 대한 첫 실행에서 내
명령 6건이 걸렸고 모두 중요하지 않았습니다. 패턴과 단어 목록은 생활에 맞춰 조정하는 것입니다.

## 보존과 삭제

- 감사 기록: **기본 90일**(`RETENTION_DAYS=90`). 실행할 때마다 만료분 삭제. `0`이면 무기한
- 격리 자료: **자동 삭제 없음**. `--purge-older 365`는 1년이 지난 날짜 폴더를, `--purge`는 전부를
  삭제합니다. 둘 다 명시적 조작입니다(격리 자료는 증거가 될 수 있으므로)
- 전부 한 번에: `exec-audit.sh --purge`

## 접근

디렉터리 `0700`, 파일 `0600`. 공유 기계에서는 이것이 경계입니다. 도구가 저장 암호화를 더하지는
않습니다. 디스크가 암호화되어 있지 않으면(FileVault, LUKS) 기록의 강도도 디스크와 같습니다.

## 제도 대응(설계상의 매핑)

- **이용 목적 특정(한국 PIPA, 일본 APPI)**: 목적은 하나, "에이전트가 무엇을 실행했는가". README에 명시
- **최소 수집(PIPA, PIPL)**: 쓰기 전 마스킹, 240자 절단, 파일 내용이 아니라 명령 줄만
- **보존 기간 제한(GDPR 5조)**: 기본 90일, 자동 만료
- **삭제 요구(APPI / PIPL / PIPA / GDPR)**: `--purge` 한 줄. 창구도 티켓도 없음
- **국외 이전 없음**: 외부로 나가지 않으므로 이전 고지가 필요 없음
- **파기(PIPA)**: 프로그램으로 확실히 삭제. 말로만 하지 않음
- **안전성 확보 조치(GDPR 32조)**: `0700`/`0600`, 수신 대기 없음, 스크립트 자체 해시로 변경 탐지

DPIA나 처리 활동 기록이 필요한 제도라면 위 목록이 그대로 대장 초안이 됩니다.

## 불편한 부분

실행 로그는 그 기계를 쓰는 사람(공유 기계라면 여러 명)의 감시 기록이기도 합니다.

1. 기계 안에 두고, 짧게 유지하고, 존재를 말한다. 숨긴 감사 로그는 다른 제품이고 윤리도 다르다
2. 로그 자체가 유출원이 되지 않게. 그래서 쓰기 전에 마스킹하고, 기본 보존은 년이 아니라 월 단위
